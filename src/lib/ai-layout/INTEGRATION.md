# Что нужно, чтобы включить боевую генерацию

Код готов и выключен. Ниже — ровно то, чего не хватает, и переменные, которыми
это включается.

## Провайдер по умолчанию — OpenRouter

Решение принято после того, как живая проверка показала: у Higgsfield нужная
модель через публичный REST недоступна, а каталога путей нет вовсе. Разбор —
в конце документа.

```
POST https://openrouter.ai/api/v1/images
Authorization: Bearer <OPENROUTER_API_KEY>
```

```json
{
  "model": "openai/gpt-image-2",
  "prompt": "…собирается на сервере…",
  "aspect_ratio": "1:1",
  "quality": "low",
  "input_references": [
    {
      "type": "image_url",
      "image_url": { "url": "https://eco-cub.ru/api/ai-layout/footprint?key=…" }
    }
  ]
}
```

Чем этот путь лучше:

- **Та же модель.** `openai/gpt-image-2` — единственная из десяти проверенных,
  давшая и точный контур, и полную планировку.
- **Каталог отдаётся программно:** `GET /api/v1/images/models`, 48 моделей.
  Ровно та проблема, из-за которой у Higgsfield пришлось искать адрес наугад.
- **Запрос синхронный.** Картинка приходит в том же ответе, механика опроса
  статуса не нужна — а это самая хрупкая часть интеграции с генерацией.
- **Стоимость приходит в ответе**, полем `usage.cost` в долларах. Не кредиты,
  а настоящая цена запроса; пишется в лог сервера.

Плата за это одна: картинка возвращается байтами в `data[0].b64_json`, поэтому
её надо хранить у себя (`store.server.ts`, раздача — `/api/ai-layout/result`).
Это скорее плюс: чужая ссылка однажды протухнет, а планировка должна
открываться и через год.

## Переменные окружения

| Переменная                                                             | Назначение                                     | По умолчанию         |
| ---------------------------------------------------------------------- | ---------------------------------------------- | -------------------- |
| `AI_LAYOUT_ENABLED`                                                    | главный выключатель функции                    | выключено            |
| `AI_LAYOUT_KILL_SWITCH`                                                | аварийный стоп, сильнее предыдущего            | выключено            |
| `AI_LAYOUT_PROVIDER`                                                   | `mock`, `manual`, `openrouter`, `higgsfield`   | `mock`               |
| `AI_LAYOUT_VISITOR_SECRET`                                             | соль для HMAC поверх IP, обязательна           | нет                  |
| `OPENROUTER_API_KEY`                                                   | ключ OpenRouter                                | нет                  |
| `AI_LAYOUT_MODEL`                                                      | идентификатор модели                           | `openai/gpt-image-2` |
| `AI_LAYOUT_QUALITY`                                                    | тариф качества                                 | `low`                |
| `AI_LAYOUT_FREE_PER_VISITOR`                                           | бесплатных генераций на посетителя             | `1`                  |
| `AI_LAYOUT_DAILY_LIMIT`                                                | потолок генераций в сутки                      | `50`                 |
| `AI_LAYOUT_PUBLIC_BASE`                                                | адрес сайта: по нему провайдер забирает контур | `https://eco-cub.ru` |
| `HIGGSFIELD_API_KEY`, `HIGGSFIELD_API_SECRET`, `AI_LAYOUT_SUBMIT_PATH` | только для провайдера `higgsfield`             | нет                  |

Ключи живут только в `/home/deploy/ecocub.env` (права 600, вне git). В браузер
уходит четыре поля — доступна ли функция, заглушка ли это, ручной ли режим и
сколько бесплатных генераций положено; проверено тестом.

## Порядок включения

1. Завести ключ на `openrouter.ai`, положить пополненный счёт.
2. Прописать `OPENROUTER_API_KEY` и `AI_LAYOUT_PROVIDER=openrouter` в
   `ecocub.env`, оставив `AI_LAYOUT_ENABLED=0`.
3. Включить флаг, собрать Г-образный дом, запросить одну генерацию.
4. Сверить контур с исходником и посмотреть в логе строку со стоимостью.
5. По настоящей цене выставить дневной лимит и только потом открывать всем.

`AI_LAYOUT_KILL_SWITCH=1` гасит функцию мгновенно, не трогая остальные
настройки.

## Что показала живая проверка 10.08.2026

Три запроса с боевым ключом дали разные ответы — и вместе они читаются
однозначно:

| Путь                          | Ответ                    |
| ----------------------------- | ------------------------ |
| `higgsfield-ai/soul/standard` | `403 not_enough_credits` |
| `openai/gpt_image_2`          | `404 model_not_found`    |
| `gpt_image_2`                 | `404 model_not_found`    |

**Ключи рабочие.** Ни одного 401: платформа принимает заголовок
`Authorization: Key key:secret`, ключи доезжают до процесса.

**Форма пути правильная.** Модель из документации разрешается и доходит до
проверки баланса. Значит синтаксис адреса был ни при чём.

**GPT Image 2 этому аккаунту через REST недоступна.** 404 на фоне 403 у другой
модели — это не опечатка в пути, а отсутствие модели в публичном API.

**У API отдельный кошелёк.** `not_enough_credits` пришёл при 189 кредитах на
балансе веб-продукта. То есть баланс `higgsfield.ai` (где работают MCP и
веб-интерфейс) и баланс консоли разработчика `cloud.higgsfield.ai` — разные
счета. Документация об этом молчит; выяснено опытом.

### Из этого следует

Барьера два, и они независимы:

1. **Пополнить счёт API** в консоли разработчика — не тот, что пополняли для
   веб-продукта.
2. **Выбрать модель, доступную в REST.** Замеры этапа 0 делались через MCP, то
   есть на каталоге веб-продукта; в REST этого каталога может не быть целиком.
   Тариф `1k` + `low` = 0.5 кредита тоже относился к GPT Image 2 и к другой
   модели не применим.

Требование к замене жёсткое: модель обязана принимать исходное изображение
массивом `medias` и удерживать контур. Из проверенных этому отвечают Kling O1
и Seedream 5.0 Pro в режиме inpaint — но их доступность в REST так же нужно
проверить, а не предполагать.
