# Что нужно, чтобы включить боевую генерацию

Код готов и выключен. Ниже — ровно то, чего не хватает, и переменные, которыми
это включается.

## Чего не хватает

1. **Точный адрес POST-запроса.** Публичная документация Higgsfield описывает
   только text-to-image (`platform.higgsfield.ai/higgsfield-ai/soul/standard`,
   `reve/text-to-image`) и не называет адрес, по которому создаётся задание с
   исходным изображением. Ассистент Higgsfield подтвердил форму тела запроса,
   но адрес назвал как «туда же, откуда берётся id для поллинга» — это не
   адрес. Спросить нужно полный URL.

2. **Пара ключей `api_key` и `api_key_secret`.** MCP-клиент работает через
   сессию владельца, а не через ключи, поэтому у сайта их пока нет. Ключи
   выпускаются в кабинете платформы; сессию владельца в production тянуть
   нельзя — это прямо запрещено техзаданием.

## Форма запроса, которую закладываем

Подтверждена дважды: видна в MCP-клиенте платформы и названа ассистентом
Higgsfield. Документацией не подтверждена, поэтому первый живой запрос —
проверка, а не формальность.

```json
{
  "job_type": "gpt_image_2",
  "prompt": "…собирается на сервере…",
  "aspect_ratio": "1:1",
  "medias": [{ "role": "image", "value": "https://eco-cub.ru/api/ai-layout/footprint?key=…" }],
  "params": { "resolution": "1k", "quality": "low" }
}
```

Подтверждено документацией: заголовок `Authorization: Key {key}:{secret}`,
опрос состояния `GET /requests/{id}/status`, статусы `queued`, `in_progress`,
`nsfw`, `failed`, `completed`, результат в массиве `images`.

Тариф `1k` + `low` выбран не наугад: по замерам этапа 0 это 0.5 кредита за
генерацию при точном контуре и полной планировке. Повышать его нет смысла —
план рисуется линиями, лишнее разрешение денег стоит, а качества не добавляет.

## Переменные окружения

| Переменная                   | Назначение                                     | По умолчанию         |
| ---------------------------- | ---------------------------------------------- | -------------------- |
| `AI_LAYOUT_ENABLED`          | главный выключатель функции                    | выключено            |
| `AI_LAYOUT_KILL_SWITCH`      | аварийный стоп, сильнее предыдущего            | выключено            |
| `AI_LAYOUT_PROVIDER`         | `mock`, `manual` или `higgsfield`              | `mock`               |
| `AI_LAYOUT_VISITOR_SECRET`   | соль для HMAC поверх IP, обязательна           | нет                  |
| `AI_LAYOUT_SUBMIT_PATH`      | адрес создания задания, обязателен для боя     | нет                  |
| `HIGGSFIELD_API_KEY`         | ключ платформы                                 | нет                  |
| `HIGGSFIELD_API_SECRET`      | секрет платформы                               | нет                  |
| `AI_LAYOUT_JOB_TYPE`         | идентификатор модели                           | `gpt_image_2`        |
| `AI_LAYOUT_RESOLUTION`       | разрешение                                     | `1k`                 |
| `AI_LAYOUT_QUALITY`          | тариф качества                                 | `low`                |
| `AI_LAYOUT_FREE_PER_VISITOR` | бесплатных генераций на посетителя             | `1`                  |
| `AI_LAYOUT_DAILY_LIMIT`      | потолок генераций в сутки                      | `50`                 |
| `AI_LAYOUT_PUBLIC_BASE`      | адрес сайта: по нему провайдер забирает контур | `https://eco-cub.ru` |

Секреты живут только в окружении сервера. В браузер уходит четыре поля —
доступна ли функция, заглушка ли это, ручной ли режим и сколько бесплатных
генераций положено; проверено тестом.

## Порядок включения

1. Получить адрес и ключи.
2. Прописать переменные на VPS, оставив `AI_LAYOUT_ENABLED` выключенным.
3. Включить флаг, сделать одну генерацию, сверить контур с исходником.
4. Только после этого поднимать дневной лимит.

Если что-то пойдёт не так — `AI_LAYOUT_KILL_SWITCH=1` гасит функцию мгновенно,
не трогая остальные настройки.
