# docs/ — общие документы проекта

Папка для durable-документов, которые должны видеть **оба агента** (облачный и
локальный): брифы, спецификации, решения, договорённости, задания. Всё, что
здесь лежит, попадает в git и доступно после `git pull`.

Этот индекс подключён автоматически в корневом `CLAUDE.md` (строкой
`@docs/README.md`), поэтому в начале каждой сессии агент видит список ниже.
Сам документ читается по необходимости — открывай нужный файл, когда задача
его касается.

## Как пользоваться

- Кладёшь `.md` в `docs/` и **добавляешь строку в список ниже** (имя + одна
  строка, о чём) — чтобы оба агента знали, что файл появился.
- Для **разового** ввода класть в `docs/` не обязательно — проще `@файл`
  прямо в чат. `docs/` — для того, что должно жить долго.

## ⚠️ Это ПУБЛИЧНЫЙ репозиторий

Никаких секретов, токенов, паролей, ключей, приватных цифр по экономике или
рекламе. Чувствительные документы (экономика, стратегия, доступы) — только в
приватном `ecocub-data`, не сюда.
