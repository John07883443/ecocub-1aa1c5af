

# План: репозиционирование сайта + сохранение SEO + страница сравнения

## Новое позиционирование

**Главное обещание сайта:**
Капитальный дом из бетона быстро, по доступной цене, с заводским качеством и гарантией. Конкурируем с **кирпичом, газобетоном, монолитом, ЖБИ-панелями** — а не с каркасниками.

**Ключевые SEO-запросы (вытащил из оригинальной Тильды + расширил под новое позиционирование):**
- модульные дома из бетона / монолитно-модульный дом
- дом из бетона под ключ / капитальный дом быстро
- современные дома Московская область / модульный дом для круглогодичного проживания
- альтернатива газобетону / альтернатива монолиту / каменный дом за 5 дней
- виллы хай-тек из бетона / модульные дома от производителя

**Уйдут из текстов и мета**: «сканди», «каркас», «Eco Wood», «деревянный дом».

## Структура сайта (после правок)

```text
/                       Главная (новое позиционирование, технология, проекты, блог)
/concrete               Бетонные модульные дома — каталог + развёрнутый SEO-текст
/villas                 Виллы Hi-Tech из бетона — премиум-линейка
```
