

## Что сделаю

Реализую все три варианта дизайна блока «Технология» как **отдельные компоненты** и покажу их **друг под другом на странице `/technology`**, чтобы вы могли пролистать и сравнить вживую. Главную страницу (`/`) пока не трогаю — там остаётся текущий вариант, чтобы было с чем сверять. После того как вы выберете победителя, удалю два проигравших и заменю компонент на главной.

## Что появится на экране

На странице `/technology` в секции с пирогом стены вместо одной иллюстрации будет три блока подряд, каждый со своим заголовком-маркером:

```text
┌─────────────────────────────────────┐
│  ВАРИАНТ A · Спецификация сбоку     │
│  [картинка]  │  01 Сталь            │
│              │  02 Бетон            │
│              │  03 ПСБ              │
├─────────────────────────────────────┤
│  ВАРИАНТ B · Выноски по краям       │
│  ← Сталь   [картинка]   Бетон →     │
│            ↘            ↙           │
│              ПСБ-С35                │
├─────────────────────────────────────┤
│  ВАРИАНТ C · Вертикальный разрез    │
│  ▓▓▓ сталь        01 Оцинк. сталь   │
│  ░░░ бетон        02 Бетон М400     │
│  ▒▒▒ утеплитель   03 ПСБ-С35        │
└─────────────────────────────────────┘
```

Под каждым вариантом — короткая подпись «A / B / C», чтобы вы могли в чате просто написать «беру B» и я доведу до ума.

## Технические детали

- Создаю три новых компонента: `LayeredSectionA.tsx`, `LayeredSectionB.tsx`, `LayeredSectionC.tsx` в `src/components/`. Существующий `LayeredSection.tsx` не трогаю.
- В `src/routes/technology.tsx` заменяю единственный `<LayeredSection />` на три блока подряд с заголовками-маркерами (`A · Спецификация сбоку` и т.д.), каждый в своём `<Section>` или внутри одной секции через разделители.
- Все три варианта используют те же три слоя данных (сталь / бетон / ПСБ-С35) и ту же картинку `/images/tech-section-clean.png` — только подача разная.
- Убираю `mix-blend-screen` с картинки во всех вариантах — он и есть причина «вымытости».
- Подписи везде на сплошном тёмном фоне (`bg-primary`, `bg-secondary` или с непрозрачной рамкой), без `bg-white/5` поверх светлой картинки.
- Главная страница `/` остаётся с текущим `<LayeredSection />` для сравнения «до/после».

## Дальнейшие шаги

После реализации вы открываете `/technology`, пролистываете три варианта, говорите «беру X». Я тогда:
1. Удаляю два проигравших компонента.
2. Переименовываю победителя обратно в `LayeredSection.tsx` (или просто меняю импорт).
3. Возвращаю на `/technology` один блок и обновляю главную.
