Список всего, что при развёртывании и работе пришлось делать руками. Каждая строка — будущая функция продукта. Без этого списка автоматизация превращается в угадайку.

Правило: **сделал руками — записал сюда сразу**, даже если кажется мелочью.

## Что из этого складывается в скрипт первичной установки

Идеальная картина: заполняется анкета клиента (домен, контакты, отрасль, счётчик, реквизиты), запускается одна команда — и через полчаса есть сервер, сайт, SSL, аналитика, бот, панель и расписание.

**Уже автоматизировано:** SSL, деплой, уведомления, атрибуция, выгрузки.

**Ближайшие цели:**
1. Скрипт первичной настройки сервера (nginx, node, pm2, swap, fail2ban, certbot) — сейчас агент делает это каждый раз заново
2. Заведение секретов в GitHub через API вместо ручного ввода
3. Анкета клиента → файл конфигурации → подстановка во все места сразу
4. Скрипт постнастройки рабочей машины (winget-набор одной командой)

**Оставляем ручным навсегда** — и это осознанно:
- всё, что требует ввода пароля или кода подтверждения
- юридические операции с доменами
- создание аккаунтов и ботов
- любые покупки

## Как пополнять

Формат строки: **что делал — кто — можно ли автоматизировать — приоритет**.

Раз в месяц список пересматривается: что из высокого приоритета сделано, что всплыло нового.

|---|---|---|---|
| Сверка рабочей копии с `origin/main` перед работой | ассистент | Да — обязательный `git fetch` в начале любой задачи | Высокий |
| Проверка наличия `.github/workflows/deploy.yml` перед коммитом | ассистент | Да — pre-commit hook или шаг CI | **Высокий** |
| Подсчёт `canonical` на странице после сборки | ассистент | Да — скрипт проверки выдачи, шаг CI | **Высокий** |
| Прогон всех адресов статей на код 200 | ассистент | Да — скрипт из `content/blog/*.md`, шаг CI | Высокий |
| Сверка числа элементов в `sitemap` и `rss` с числом файлов | ассистент | Да — тот же скрипт | Высокий |
| Проверка, что форма заявки и аналитика не задеты релизом | ассистент | Да — сравнение хешей критичных файлов с базовой версией | Средний |
| Определение приоритета `location` в nginx вручную | ассистент | Частично — линтер конфигурации | Средний |
| Инвентаризация медиа в папке материалов | ассистент | Да — скрипт обхода с отбором по разрешению | Средний |
